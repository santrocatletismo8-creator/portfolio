De la URL a la página

Cuando escribo una dirección en el navegador pasan varias cosas:

  1. Escribo la URL en el navegador y pulso Enter.
  2. El navegador pregunta a un servidor DNS cuál es la dirección IP de ese dominio.
  3. Se conecta a esa IP y envía una petición HTTP al servidor.
  4. El servidor responde con los archivos de la página (HTML, CSS, imágenes…).
  5. El navegador lee el HTML y dibuja la página en pantalla.

Herramientas que uso

Herramientas que uso

  • Visual Studio Code: el editor donde escribo mi código.
  • Live Server: extensión que me deja ver la página en el navegador y se actualiza al guardar.
  • Git: guarda las versiones de mi trabajo en mi ordenador.
  • GitHub: guarda mi repositorio en internet y me permite publicarlo.
